# Компас отношений / Relationship Compass

Еженедельная, квартальная и годовая практика ревью отношений для пар и семей (в любой конфигурации). Вдохновлена ретроспективами вроде YearCompass, исследованиями Готтмана и «меню компонентов отношений» (non-escalator relationship menu), популярным в среде полиамории и relationship anarchy.

Двуязычный интерфейс (RU/EN), компас-диаграмма по 7 областям, редактируемое меню компонентов отношений, структурированные таблицы для разбора конфликтов и целей, история записей с сохранением по дате.

**Демо:** https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПО/

## Как это работает

Это один статический HTML-файл. Вся логика — на чистом JavaScript, без сборки и зависимостей. Все ответы пользователя сохраняются в `localStorage` его собственного браузера и никогда никуда не отправляются — ни на сервер, ни куда-либо ещё. Владелец сайта не может увидеть содержимое чужих записей.

## Локальный запуск

Просто откройте `index.html` в браузере — сервер не нужен.

## Деплой на GitHub Pages

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`, папка `/ (root)`
4. Сохранить — через 1–2 минуты сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПО/`

## Статистика посещений (без сбора чужих данных)

Файл содержит закомментированную заготовку под [GoatCounter](https://www.goatcounter.com/) (бесплатно, open source, без cookies и без сбора личных данных) — раскомментируйте нужный `<script>` в `<head>` файла `index.html` и впишите свой код после регистрации на сайте GoatCounter.

Альтернатива: если сайт на Cloudflare Pages — включите Cloudflare Web Analytics прямо в дашборде, ничего в код добавлять не нужно.
